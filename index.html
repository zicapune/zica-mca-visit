Code Lab 1 of 7 · Texture

    
Every photo is a 2D array.

    

      

        
  filter.js

        
You learned this as 2D arrays and matrices.

        
A sunset. Or is it?

      

      

    

    
    
WHAT YOU'RE SHOWING: a photo is just a grid of numbers (0–255 per pixel). A filter is a tiny 3×3 grid of numbers (the "kernel") that slides over every pixel: new pixel = C × the pixel itself + N × each of its 8 neighbours, then divided by the total so brightness stays the same. That is a nested for-loop over a 2D array, the code on the left. CLICKS: 1 zooms into the pixels so the numbers show. 2 = edge detection (C 8, N −1). 3 = blur (C 1, N 1). HOW TO CHANGE IT YOURSELF: hover an amber number in the code, hold the mouse button and drag right to increase, left to decrease. C (centre) = how much of the pixel itself. N (neighbours) = how much of the 8 pixels around it. RECIPES: C 1, N 0 → the original photo. C 1, N 1 (or C 0, N 1) → blur, "everything averages with its neighbours". C 1, N 2 → stronger blur. C 9, N −1 → sharpen, "every pixel pushes away from its neighbours". C 12, N −1 → gentle sharpen. C 8, N −1 → edge detection: flat areas go black, only outlines stay. C −4, N 1 → soft, ghostly. Rule to say out loud: "neighbours positive = blur, neighbours negative = sharpen or edges." Line: "Every filter in Photoshop and Instagram is a small grid of numbers sliding over a big grid of numbers. That is a nested for-loop you wrote in second semester." Python
Tools inside Blender and Maya
Studios write Python to automate their software: one script places a thousand trees or renames 5,000 files.
Every big studio has a "pipeline TD" writing this all day.
GLSL / HLSL
Shaders
Tiny programs that run on the graphics card for every pixel, every frame. GLSL is OpenGL's shading language; HLSL is Microsoft DirectX's.
Every glow, water surface and skin tone in a game is a shader.
C++ / Blueprints
Unreal Engine games
Unreal is written in C++. Blueprints are its visual scripting: the same logic as code, wired as boxes.
Our Game Art students build gameplay with Blueprints.
Pipeline scripts
Studio automation
Code that moves every asset from department to department, versions it (v001, v002…) and sends it to the render farm.
Without it, a 2-hour film is chaos.
Three.js / WebXR
3D and AR in the browser
JavaScript libraries that put real-time 3D and augmented reality on a web page. No app to install.
Product configurators, virtual try-ons, museum tours.
APIs + AI
Generative workflows
Calling image, video and voice models from code, and wiring them into real production.
The fastest-growing job in studios right now.
